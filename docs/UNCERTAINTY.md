# Реестр неопределённости

Что именно агент не знает, сколько этого, чем наводится, почём и с каким
качеством. Документ определяет три вещи: формат ответов клиенту, очередь работ и
то, как в систему ложатся внешние цены.

Все доли в первой колонке **измерены на датасете**, а не оценены. Команды для
пересчёта — в конце. База: анализируемые позиции продуктового ядра, **14 782
позиции на 3 665 593 ₽** (из 19 056 позиций всего; разница — исключённые
и безымянные чеки, см. строку «Площадка»).

Дата замера: 2026-09-13, конец истории 2026-09-05.

---

## Реестр

### 1. Категория (товарная группа)

| | |
|---|---|
| **В неопределённости** | 1 696 позиций (11,5%), 468 705 ₽ (12,8%) |
| **Чем наводится** | правило в конфиге `categories.json` — и почти ничем сверх того |
| **Цена наведения** | минута на правило, но правил нужно 1 510 |
| **Качество результата** | достоверно |

Наводится дешёвым средством, но наводить нечего: **1 510 различных названий на
1 696 позиций** — 1,12 позиции на название. Из них **1 324 названия (88%)
встречаются ровно один раз**, и в них 379 149 ₽ из 468 705 ₽. Очередь Б (названия
от трёх покупок) пуста — она разобрана.

Концентрации нет: топ-100 названий по деньгам закрывает 29,2% денег этого класса,
топ-365 — 59,2%. Это не хвост, который дочищается за вечер; это природа
покупок: разовые товары остаются разовыми.

### 2. Марка (бренд)

| | |
|---|---|
| **В неопределённости** | 3 858 из 6 265 штучных позиций с фасовкой (61,6%), 952 716 ₽ (65,5% денег этого класса) |
| **Чем наводится** | правило в `brands.json`; для части — только подтверждение пользователем |
| **Цена наведения** | минута на правило; названий без марки 1 772, из них 365 встречаются ≥3 раз |
| **Качество результата** | достоверно для точного совпадения; вероятно — для правила по образцу |

Единственный класс, где работа окупается прямо: марка — то, что превращает
«группа · — · 0,3 кг» в товар, цену которого можно сравнивать (Р-21, Р-24).
Внутри постоянной корзины без марки **3 364 позиции (29,1%) на 735 523 ₽**.

Но и здесь концентрации нет: топ-10 названий — 10,6% денег класса, топ-100 —
39,5%. «Час разбора» закроет проценты, а не класс.

Качество зависит от формы правила. Правило на точное название достоверно.
Правило по образцу (`^ДСК\b`) перехватывает и то, чего не видели, — поэтому оно
проверяется измерением эффекта (Р-24), а не принимается на веру.

### 3. Фасовка

| | |
|---|---|
| **В неопределённости** | 3 503 из 9 768 штучных позиций (35,9%), 893 615 ₽ (38,1%) |
| **Чем наводится** | правило — только для 38% этого класса; для 62% — **ничем, кроме внешнего источника или пользователя** |
| **Цена наведения** | минута на правило; для 2 182 позиций правила не существует в принципе |
| **Качество результата** | достоверно, если фасовка есть в названии; иначе правдоподобно без оценки |

Здесь проходит первая настоящая граница. **У 2 182 позиций из 3 503 (62%,
496 083 ₽) в названии нет ни одной цифры**: «АВОКАДО», «САХАР ТЕМ ТРОСТ КУС»,
«ЛАПША ГРЕЧН.СЕН-СОЙ». Извлекать нечего — ни одно правило не достанет из этой
строки граммы. Остаются два пути: внешний каталог или вопрос пользователю.

Оставшиеся 1 321 позиция — с цифрой в названии, но правило не сработало:
«КЕФИР 3,2% В БУТЫЛКЕ,ШТ», «КОЗЬЕ МОЛОКО 3.5-4.8». Вот это правится правилами,
и это честная очередь работ.

### 4. Жирность

| | |
|---|---|
| **В неопределённости** | 2 786 из 4 218 позиций в группах, где жирность бывает (66,1%), 503 225 ₽ (68,7%) |
| **Чем наводится** | **ничем из названия**; только внешний источник или пользователь |
| **Цена наведения** | недоступно правилом |
| **Качество результата** | правдоподобно без оценки |

Самая глухая строка реестра. В молочных группах без жирности 1 185 позиций на
201 818 ₽, и **у 100% из них в названии нет знака «%»**: «МОЛОКО КОЗЬЕ 450 МЛ,ШТ»,
«СЛИВКИ СВИТЛ.10 500Г». Правило читает процент; если процента нет, читать нечего.

Важно, что это не ломает сравнение цен: неизвестная жирность входит в ключ как
«—» и не смешивается с известной. Товар с неизвестной жирностью сравнивается сам
с собой. Цена неопределённости здесь — не ошибка, а дробление: один товар
распадается на два ключа, и каждому не хватает наблюдений до порога.

### 5. Базовая единица

| | |
|---|---|
| **В неопределённости** | 5 199 позиций (35,2%), 1 362 320 ₽ (37,2%) — **производная, своей неопределённости нет** |
| **Чем наводится** | наводится сама, как только известны группа и фасовка |
| **Цена наведения** | ноль: отдельной работы не требует |
| **Качество результата** | достоверно |

Проверено: единица неизвестна ровно там, где неизвестна группа (1 696) или
фасовка (3 503), и больше нигде — пересечение пустое, сумма сходится точно.
Отдельным параметром её вести не нужно, и в очередь работ она не попадает.

Отдельно — смена способа продажи: один и тот же товар продаётся то на вес, то
поштучно, и ₽/кг сравнивается с ₽/шт под одним именем. На датасете таких рядов
**1 из 206**. Он отсекается автоматически (Р-21).

### 6. Площадка (продавец)

| | |
|---|---|
| **В неопределённости** | 906 позиций, 130 805 ₽ — **3,4% всех денег прогона**, 146 дат |
| **Чем наводится** | классификацией по составу чека — уже сделана; дальше только подтверждение пользователем |
| **Цена наведения** | одно подтверждение на чек; изменение поведения — не требуется |
| **Качество результата** | вероятно, с оценкой (доля продуктовых позиций в чеке) |

Чеки без продавца классифицированы по составу позиций (§7) и живут в отдельном
ярусе `unknown_food`, который **по умолчанию выключен** и в базу покрытия не
входит. Это сознательно: включение сливает «Агроаспект» с Перекрёстком.

Отдельная разновидность — площадка известна, но товар куплен только в ней:
сравнивать не с чем. Это не неопределённость данных, а свойство покупок, и
лечится оно единственным способом — купить тот же товар в другом месте. Внутри
недельной корзины таких строк 2 из 8.

### 7. Возраст цены

| | |
|---|---|
| **В неопределённости** | по позициям: 9 554 (64,6%), 2 262 415 ₽ (61,7%) старше 24 месяцев. По ответу — **измерять надо возраст цены у той площадки, куда ведёт маршрут**: до Р-27 старше двух лет были 13 сравнений из 25 и все 4 строки недельного маршрута |
| **Чем наводится** | только новой покупкой — то есть изменением поведения; либо внешним источником цен |
| **Цена наведения** | недоступно агенту: цену делает не он |
| **Качество результата** | внутри окна — достоверно, с напечатанным возрастом; за окном — сравнение не строится |

Две разные цифры, и путать их нельзя. 61,7% денег старше двух лет — это глубина
истории за девять лет, а не порок. Для ответа важна другая: у товаров, по которым
агент реально отвечает, медианный возраст последней покупки — **4 месяца**, и лишь
3 из 25 не покупались два года.

Каталог замен (8.3) берёт цены из окна в 24 месяца именно поэтому: цена 2017 года
не является предложением в 2026-м (Р-22).

**Найдено этим замером, закрыто Р-27 — но не так, как здесь предполагалось.**
Замер начинался с возраста товара: три сравнимых из 25 не покупались больше двух
лет. Оказалось, что мерить надо не это. Маршрут ведёт в самый дешёвый магазин, а
самым дешёвым оказывается тот, куда человек перестал ходить: у 13 сравнений из 25
цена дешёвой площадки была старше двух лет, а в недельном маршруте устаревшими
были ВСЕ четыре строки — лук во «ВкусВилле» по цене девятилетней давности.

Дефект был не в отсутствии пометки, а в самом сравнении: медиана считалась по
всей истории у каждой площадки отдельно, и «в Ленте дешевле» означало разницу лет,
а не магазинов. Сужение окна роняло экономию недели 334 → 192 → 68 ₽ — подпись
временного артефакта, а не разницы площадок.

Теперь окно одно на всю систему (`history.PRICE_WINDOW_MONTHS`), 8.3 по нему
исключает, 8.6 сравнивает внутри него и печатает возраст оставшегося. Цена: 25 →
14 сравнимых товаров, 334 → 68 ₽ экономии. Это отказ от ответа, которого не было.

### 8. Сопоставление с внешним источником

| | |
|---|---|
| **В неопределённости** | 100%: сопоставлений нет ни одного, внешнего источника не подключено |
| **Чем наводится** | внешним каталогом — и только по названию: **в чеках нет кода товара** |
| **Цена наведения** | недоступно сейчас; при появлении каталога — сопоставление 5 752 названий |
| **Качество результата** | вероятно с оценкой в лучшем случае; правдоподобно без оценки — в типичном |

Ключевой факт, определяющий всю строку: **позиция чека несёт только имя, цену,
количество и сумму**. Ни штрихкода, ни номенклатурного кода, ни GTIN. Значит
любое сопоставление с внешним каталогом — сопоставление строк, и оно
вероятностное по природе.

Что сопоставимо хотя бы структурно: полный ключ «группа + марка + фасовка» есть у
**2 407 позиций (16,3%), 500 926 ₽ (13,7%)**; с жирностью — у 800 (5,4%).
Остальное — либо весовое (3 411 позиций, 23,1%, где марка неприменима по
построению), либо с пробелами, описанными выше.

**Как из этого следует, что внешние цены нельзя смешивать со своими.** Медиана по
собственным чекам — единственное, что известно достоверно: это заплаченные
деньги. Внешняя цена приходит через вероятностное сопоставление имени. Смешать их
в одну медиану значит заразить достоверное правдоподобным и потерять возможность
отличить одно от другого навсегда. Поэтому внешняя цена входит отдельным полем,
с источником, датой и оценкой качества сопоставления, и в ответе называется
отдельно: «в магазине X сейчас Y ₽ (источник, сопоставлено по названию)».

## Что агент говорит клиенту

Сейчас ответов два — «задание» и «не лечится». Классов семь, и они различаются не
тоном, а тем, что клиент может с ними сделать.

### 1. Достоверно

> Корзина на неделю дешевле всего в Глобусе — 1 246 ₽; врозь по четырём
> магазинам 912 ₽, экономия 334 ₽.

Число называется без оговорок. Так отвечает всё, что посчитано по собственным
чекам внутри одного товара.

### 2. Достоверно, но по другому товару вашей группы

> Сравнили по «Оксское · 30 шт» вместо «— · 10 шт»: эту марку вы берёте в 82%
> случаев от самой частой.

Число достоверно, но относится не к тому товару, о котором думал клиент.
Подстановка называется всегда (Р-25).

### 3. Достоверно как факт прошлого, устарело как ориентир

> Творог «Савушкин» дешевле в «Магните» — 457 ₽/кг. Этой цене 17 месяцев.

Реализовано (Р-27). Внутри окна сравнения возраст печатается рядом с ценой: он
бывает и полтора года, и это стоит знать до поездки. За окном сравнение не
строится вовсе — не потому, что старое плохо, а потому что сравнивать цену 2017
года с ценой 2026-го нельзя: получится измерение инфляции, а не разницы
магазинов.

### 4. Наводится вашим подтверждением — вопрос, а не задание

> «МОЛОКО КОЗЬЕ 450 МЛ, ШТ» — это 0,45 л? Подтвердите, и товар войдёт в
> сравнение цен.

Новый класс. Сюда попадает всё, чего нет в названии: фасовка без цифр (2 182
позиции), жирность без процента (1 185 позиций), продавец безымянного чека.
Правилом это не берётся, а одним кликом — берётся. Цена — минута внимания
клиента, и спрашивать надо в порядке денег корзины, а не подряд.

### 5. Наводится правилом — задание в очередь

> Строка «Бытовая химия» на 442 ₽ не разводится по магазинам: марка не
> распознана. Разметить: ЖИД.МЫЛО ВЕСТАР 1Л, ЖИДК.Д/РОЗЖИГА 1Л…

Существующий класс, без изменений. Эффект каждого правила измеряется (Р-24).

### 6. Не лечится ничем, что зависит от нас

> Молоко «Бежин луг» вы берёте от трёх раз только в Глобусе — сравнить его цену
> не с чем. Это свойство ваших покупок, а не пробел в данных.

Существующий класс, но формулировку надо править: сейчас он называется «не
лечится», и это звучит как отговорка. Честнее назвать причину и не предлагать
действия, которого нет.

### 7. Неустранимо по природе — и об этом молчим

Разовая покупка, которая больше не повторится: 1 324 названия на 379 149 ₽.
Заводить под них правила бессмысленно, показывать их клиенту как работу —
вредно. Они учитываются в контроле трат (каждый рубль на месте) и не
показываются в очередях.

### 8. Правдоподобно без оценки — **не говорим числом**

> В этой группе агент не может назвать цену за килограмм: фасовка неизвестна.

Прямое следствие §8.9 и Р-26. Если качество результата — «правдоподобно без
оценки», число не печатается вовсе. Не «примерно 300 ₽/кг», не «около», не
«ориентировочно»: у клиента нет способа отличить оценку от измерения, а у нас
есть — и мы обязаны им пользоваться.

## Что отсюда следует для очереди работ

Порядок задан деньгами корзины и наличием средства, а не размером класса:

1. **Марка внутри постоянной корзины** — 735 523 ₽, правится правилом, эффект
   измерим и попадает прямо в главный ответ.
2. **Фасовка с цифрой в названии** — 1 321 позиция, правится правилом.
3. **Подтверждения пользователем** — фасовка без цифр и жирность без процента,
   в порядке денег корзины; по одному вопросу, а не списком.
4. **Категория** — только если название встречается от трёх раз; сейчас таких нет.
5. **Всё остальное** — не работа. В очередь не ставится.

## Что отсюда следует для внешних цен

- Внешняя цена **не входит** в медиану по собственным чекам.
- Внешняя цена хранится с источником, датой и оценкой сопоставления.
- В ответе называется отдельно и всегда с источником.
- Сопоставление без кода товара — вероятностное; при качестве ниже порога
  внешняя цена не показывается вовсе (класс 8).

## Как пересчитать

Все цифры получены на `data/receipts.json` (1 744 чека, 19 056 позиций) и
воспроизводятся прогоном. Общие показатели покрытия:

```bash
python3 validate.py                 # покрытие, очереди, сравнимость
python3 cli.py venues --basket week # что из этого видно в ответе
```

Разрезы этого документа считаются поверх `agent.adapters.receipts_fns.diagnostics`
и `agent.reach`; при смене датасета пересчитывать надо всё — доли меняются вместе
с составом покупок.
