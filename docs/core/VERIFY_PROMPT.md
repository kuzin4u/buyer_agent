# Промпт сверки документов с кодом (для Claude Code)

> Запускать из корня репозитория; то же делает команда `/verify`. Первая сверка — 2026-09-23.

```
Прочитай все файлы в docs/core/. Затем проверь каждое утверждение по реальному коду,
схеме базы и конфигурации репозитория.
1. Исправь в docs/core/ всё, что расходится с кодом. Код — источник истины для
   «как есть»; SPEC и DECISIONS — источник истины для «как должно быть».
2. Замени метки ⟦уточнить⟧ фактами из кода, если они там есть.
3. Каждое расхождение «должно быть ≠ есть» запиши в docs/core/STATUS.md
   в раздел «Расхождения» с приоритетом (критично / важно / позже).
4. Ничего не удаляй из DECISIONS.md — только добавляй.
5. В конце выдай список изменений по файлам.
Не меняй код в этом проходе — только документы.
```
