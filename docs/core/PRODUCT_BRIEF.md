## Что это
Персональный AI-агент-закупщик. Анализирует историю покупок по собственным чекам ФНС
(выгрузка JSON из приложения «Проверка чеков»), помогает собирать корзину,
сравнивать магазины и отслеживать подорожание, ведёт учёт трат (SPEC §1).

## Тип агента
- **Ядро А — аналитик-советчик** (текущий этап): восемь функций 8.1–8.8, реализованы.
- **Расширение Б — активный закупщик** (оформление заказа, автонапоминания, уведомления о подорожании) — задел, SPEC §9.

## Главный сценарий готовности
«Покажи варианты моей корзины в разных магазинах». Реализован как `agent/plan.py` и страница
`/plan`: три варианта — в одном месте (`single`), врозь по маршруту экономии (`split`),
под бюджет (`budget`); доля разведённых строк печатается рядом с экономией (Р-2, Р-21).
Первый экран веба `/` — кнопки сценариев и свободный запрос; первая кнопка — «Продукты на неделю»
(`plan`, первым в `config/intents.json`), запрос «продукты на неделю» сразу ведёт на `/plan`.

## Целевой сценарий
Команда «продукты на неделю» → агент предлагает варианты корзины с комментариями →
пользователь выбирает один → список покупок, разложенный по магазинам.
**Есть:** варианты, выбор и список на `/plan`, отправка списка в Telegram через очередь `outbox`.
**Нет (расширение Б, SPEC §9):** выгрузка корзины в заказ магазина — это внешние интеграции
(API магазина, ссылки на товары), вне кода ядра.
Комментарии к вариантам словами даёт только умный слой при заданном ключе.
