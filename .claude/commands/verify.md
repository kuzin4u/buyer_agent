---
description: Сверить документы docs/core/ с кодом и записать расхождения
---
Прочитай все файлы в docs/core/. Проверь каждое утверждение по реальному коду, схеме базы и конфигурации репозитория.

1. Исправь в docs/core/ всё, что расходится с кодом. Код — источник истины для «как есть»; спецификация и DECISIONS.md — для «как должно быть».
2. Замени метки ⟦уточнить⟧ фактами из кода, если они там есть.
3. Каждое расхождение «должно быть ≠ есть» запиши в docs/core/STATUS.md, раздел «Расхождения», с приоритетом: критично / важно / позже.
4. DECISIONS.md — только дополнять, ничего не удалять.
5. Код в этом проходе не меняй — только документы.
6. В конце: список изменений по файлам и отдельно — утверждения, которые не удалось проверить по коду.
