argument-hint: [что проверять — по умолчанию изменения с последнего коммита]

Поручи подагенту **reviewer** независимое ревью.

Объект ревью: $ARGUMENTS
Если пусто — незакоммиченные изменения (`git diff HEAD`); если их нет — последний коммит (`git show HEAD`).

Передай подагенту только объект ревью и указание на документы (SPEC.md, docs/DECISIONS.md, docs/core/RULES.md — если есть). Не передавай свою историю рассуждений и объяснения, почему код написан так: ревью должно быть независимым.

Верни его вывод полностью, без смягчений. Затем по каждому замечанию коротко: согласен / не согласен и почему. Ничего не исправляй без моего решения.
